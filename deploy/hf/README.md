# ParallaX — SPHEREx blink comparator

Type a star name or coordinates and watch every SPHEREx visit of that patch of sky play like a short video, so
moving stars and brown dwarfs hop and varying objects pulse. Built for the NASA Space Apps Challenge 2026.

This Space builds the app from its GitHub repository (see `Dockerfile`).
